# CreditFlow UI

Build a modern enterprise web application UI for the Apexon Credit Intelligence Fabric described in the attached document.

Use the document as the source of truth for the product workflows and MVP scope.

Focus on the Phase 1 commercial underwriting MVP. Create realistic screens for:

 Underwriting dashboard

 Credit case/application

 Document intake and document review

 Financial spreading and ratios

 Credit policy & KYC checks

 AI/domain-agent insights

 Underwriter recommendation and decision

 Full audit trail

Use realistic mock data for now. Build the frontend only; backend/API integration will be added later.

Make it look like a professional enterprise banking/credit underwriting platform.
